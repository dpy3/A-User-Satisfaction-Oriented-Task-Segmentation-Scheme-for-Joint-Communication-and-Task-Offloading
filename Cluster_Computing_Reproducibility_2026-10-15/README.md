# Paper 1 — repair-aware fog scheduling

Target: *Cluster Computing* (Springer Nature official `sn-jnl.cls` source is under `manuscript/springer_official/`).

## Package map

- `code/`: MATLAB/Python source, runners, analysis scripts and frozen-protocol notes from `MCA_Official_2026`.
- `data/figure_source_data/`: source tables used to draw the final Springer figures.
- `data/FORMAL_FIXED5/`: official static M-CA-ALM versus GA-Hybrid evidence.
- `data/BASELINEFORMAL_FIXED5/`: implemented baseline comparison.
- `data/ABLATIONFORMAL_FIXED5/`: repair-aware ranking/guard factorial evidence.
- `data/REPAIRTRANSFERFORMAL_FIXED5/`: independent GA-family repair-transfer validation.
- `data/OFFLINEGNN_FORMAL_FIXED5/`: split-isolated internally trained learned comparator.
- `data/SELECTORFORMAL_FIXED5/`: formal 500-slot replay at the recoverable and immediate-overload loads.
- `data/SELECTORV9FORMAL_FIXED5/`: held-out overload-aware selector replay evidence.
- `data/SELECTORV9N300REPLICATION_FIXED5/`: separate N=300 replication evidence.
- `figures/`: canonical PDF/SVG/PNG/TIFF exports.
- `manuscript/springer_official/`: current Springer source, bibliography, sections, PDF and audit notes.
- `submission_docs/`: cover letter, submission brief and transfer/audit notes.

## Main entry points

1. Read `code/README_MCA_OFFICIAL.md` and the protocol notes before execution.
2. Configure MATLAB paths to include `code/` and its subfolders.
3. Use the relevant runner (`Run_MCA_Official_Static.m`, `Run_MCA_Official_Replay.m`, `Run_MCA_Repair_Transfer.m`, or `Run_MCA_Offline_GNN_Baseline.m`).
4. Use the corresponding `Analyze_*.m`/`Analyze_*.py` script to regenerate summaries and figures from the result tables.

The included outputs are the evidence used in the manuscript; rerunning is optional and may be computationally expensive.

## Canonical evidence mapping

The static satisfaction and additional-baseline tables are generated from
`data/BASELINEFORMAL_FIXED5/`. The mechanism-ablation table is generated from
`data/ABLATIONFORMAL_FIXED5/`; repair-transfer and learned-comparator results
come from their correspondingly named frozen packages.
The similarly named `data/FORMAL_FIXED5/` directory is retained as a
historical selector-pipeline diagnostic and must not be substituted for the
Table 2--5 source. Its static ALM values differ because it was generated by
the earlier selector configuration. The manuscript's main claims must always
be regenerated from the canonical `BASELINEFORMAL_FIXED5` files.

## Claim boundary

The evidence is limited to the fixed five-node simulator and the tested load/replay regimes. The package does not support claims of cross-topology generalization, real deployment performance, or universal superiority over all learned schedulers.
