# Cluster Computing reproducibility package

This directory contains the frozen source, code, run-level data, figure-source data, and audit notes for the manuscript **Outcome-Aligned Task Offloading for DNN Inference in Heterogeneous Fog Networks**.

The package is scoped to the fixed five-node simulator, the tested loads and replay protocols, the shared repair operator, and the algorithms described in the manuscript. It does not support cross-topology or deployment claims.

Start with `README.md`, `ENVIRONMENT.md`, and `code/README_MCA_OFFICIAL.md`.
