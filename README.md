# Reproducibility repository

This repository contains source code and reproducibility materials for mobile-edge/fog-computing studies.

## Current Cluster Computing manuscript package

Use [`Cluster_Computing_Reproducibility_2026-10-16/`](Cluster_Computing_Reproducibility_2026-10-16/) for the current manuscript, code, Strict V2 data, complete 500-slot replay, analysis, and audit records. The downloadable archive is [`Cluster_Computing_Reproducibility_2026-10-16.zip`](Cluster_Computing_Reproducibility_2026-10-16.zip). The folder includes a SHA-256 manifest and states the scope and limitations of the synthetic evidence.

The `Cluster_Computing_Reproducibility_2026-10-15/` directory is an earlier version and is retained for version history; cite and use the 2026-10-16 package for the current manuscript.

The older directories `Original_Algorithm/` and `Refined_Simulation/` are retained as repository history for the earlier task-offloading project.
